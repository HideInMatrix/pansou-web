## 前言

docker 技术虽然发展了很多年，而且 k8s 表示不再支持它，但是这个容器技术目前拿来玩一玩还是不错的，装 docker-compose 则能一次控制多台容器。

## 安装

1. 安装 docker 商店安装或者使用下面的命令安装

```shell
curl -sSL <https://get.docker.com/> | sh
systemctl enable --now docker
```
