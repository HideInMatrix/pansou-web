## 前言

现在听个歌曲可费劲了，QQ 音乐，虾米音乐，网易云音乐 都得安装上！之前很简单的一个事情，现在弄的这么复杂

而网易云音乐相信不需要我过多的介绍大家也都知道，很多人在听歌的时候也注意到了，由于各种限制很多的音乐呈现灰色的样式，是无法播放的。如下图所示，今天就**带大家把灰色不能听的音乐全部变成可以正常播放的音乐**

![112e1348db3738068ac17.png](https://pan.micromatrix.eu.org/file/112e1348db3738068ac17.png)

今天给大家分享三种方法解锁网易云灰色音乐，当然除此之外网上还有很多解锁的教程，但我还是觉得这三种方法比较简单有效。

> 本文发布时亲测有效，大家且用且珍惜！

## 搭建一个自己的节点

使用 docker 部署一个 docker 镜像就可以，如果你不会 docker 或者不了解 linux 服务器，那你就去搜索下

```shell
docker run -d  -e ENABLE_FLAC=true -e ENABLE_LOCAL_VIP=true  -p 70:8080 --name unblock163  --restart=always pan93412/unblock-netease-music-enhanced  -e "https://music.163.com" -f 59.111.160.195
```

## 解锁原理

使用网易云旧链 / QQ / 虾米 / 百度 / 酷狗 / 酷我 / 咕咪 / JOOX 音源替换变灰歌曲链接 (默认仅启用前四)

### 解锁方法一：通过软路由 OpenWrt 系统全家解锁

OpenWrt 是最常用的软路由系统，里面可以安装非常多而且实用的功能，方法一就是用其中的\***\*解锁网易云音乐插件\*\***来实现。

对于没有软路由的小伙伴也可以通过废旧笔记本/台式机或者虚拟机安装 OpenWrt 系统。关于 OpenWrt 系统的安装及使用方法网上有大把的教程可以学习，由于不是今天的重点，本文就不过多介绍！

1. OpenWrt 设置吧

   1. 首先找到 OpenWrt 系统内的插件-解锁网易云灰色歌曲

      ![ff4de390d12450e8d0b4f.png](https://pan.micromatrix.eu.org/file/ff4de390d12450e8d0b4f.png)
   2. 在启用后面 ✔ 打勾，解锁程序选择-NodeJS 版本，音源选择酷我音乐(其他音源自行尝试)，右下角点击保存并应用。
   3. 确定插件开始运行。

      ![8155b22bcced56ffe539f.png](https://pan.micromatrix.eu.org/file/8155b22bcced56ffe539f.png)

## 各平台使用方法

### Windows 系统

打开网易云音乐-设置-工具-自定义代理-服务器填入 OpenWrt 的 IP 地址，端口填写 5200-点击确定-现在重启即可。

![5a736ee83f91250d82678.png](https://pan.micromatrix.eu.org/file/5a736ee83f91250d82678.png)

刚重启可能会提示网络错误，不用在意，直接搜索周董歌曲试试吧！

![362d23224afc3929302e6.png](https://pan.micromatrix.eu.org/file/362d23224afc3929302e6.png)

![15d6c33fd443419e45491.png](https://pan.micromatrix.eu.org/file/15d6c33fd443419e45491.png)

### **安卓系统**

先后台退出网易云 APP，然后在连接的 Wifi 名上按住 1 秒-点击修改网络-选择静态 IP-把网关和下面的域名 1(DNS)设置成 OpenWrt 的 IP 地址，确保手机数据流量都经过软路由。此时重新打开网易云音乐，比如搜索周董的专辑，会发现所有歌曲全部解锁可以正常播放。

![330b4566151f79168fc7e.png](https://pan.micromatrix.eu.org/file/330b4566151f79168fc7e.png)

### **ios 系统**

ios 系统比较特殊，需要先下载并信任 CA 证书才可以。

首先用 ios 手机浏览器打开本页面，直接点击链接：[证书](https://raw.githubusercontent.com/nondanee/UnblockNeteaseMusic/master/ca.crt),在弹出的对话框中点击允许下载 CA 证书，然后进入设置 → 通用 → 描述文件 → 安装 CA 证书并在设置 → 通用 → 关于本机 → 证书信任设置开启对 CA 证书的信任。
然后和安卓类似，设置手机静态 IP，网关和 DNS 同样设置成 OpenWrt 系统的 IP 地址，打开网易云音乐即可解锁！

1. 通过 ShadowRocket 节点解锁

   1. 首先获取 CA 证书并信任方法同上
   2. 然后打开小火箭，左上角点击扫描下方二维码添加节点:
   3. 来到配置文件项-添加配置-输入以下链接，下载成功后点击使用配置

      [https://raw.githubusercontent.com/w37fhy/QuantumultX/master/NeteaseMusic.conf](https://raw.githubusercontent.com/w37fhy/QuantumultX/master/NeteaseMusic.conf)
   4. 来到设置项-找到 UDP-取消开启转发
   5. 回到首页-选择刚才导入的节点-全局路由选择配置-打开连接即可。

### MacOS 系统

同 ios 方式相同，安装并信任 CA 证书，然后设置静态 IP+网关+DNS 即可。

**安装信任证书步骤**

1. 使用 Safari 浏览器打开 OpenWrt 后台，找到解锁网易云灰色歌曲插件，点击下载 CA 根证书（可能需要科学上网环境才能打开）。

   ![8039d23522879e1ca7a33.png](https://pan.micromatrix.eu.org/file/8039d23522879e1ca7a33.png)
2. 在打开的页面，右键-将页面存储为..-选择保存格式为页面源码-导出文件名为.crt 结尾

   ![2a9257a96ce1b1b4d9a78.png](https://pan.micromatrix.eu.org/file/2a9257a96ce1b1b4d9a78.png)
3. 双击打开保存的 CA 证书-弹出询问是否添加到钥匙串-点击添加-在钥匙串中打开添加进来的证书，在信任下面的选项：使用此证书时：后面更改为-始终信任即可！

   ![025b649dcbc05d7527d1e.png](https://pan.micromatrix.eu.org/file/025b649dcbc05d7527d1e.png)

   ![bbd2a9bf513b7b841dec2.png](https://pan.micromatrix.eu.org/file/bbd2a9bf513b7b841dec2.png)
