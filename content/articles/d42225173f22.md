## 解决方法

之前给 linux 做过代理配置。好久没用，代理失效了。其中设置了端口也不知道在哪里设置的

1. 定位问题

```shell
sudo netstat -ntpl
```

发现并没有服务在占用端口 8889

2. 查看本地网络是否走了代理服务

```shell
export | grep -i proxy
```

在找到了被占用的端口的 8889， 确实是走了代理，于是问题找到了。
解决方法

```shell
#关闭服务
unset https_proxy
```
